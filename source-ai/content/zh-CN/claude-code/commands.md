# 命令

> Claude Code 中可用命令的完整参考，包括内置命令和捆绑技能。

命令从会话内部控制 Claude Code。它们提供了一种快捷的方式来切换模型、管理权限、清除上下文、运行工作流等。

输入 `/` 查看您可以使用的所有命令，或输入 `/` 后跟字母进行筛选。

命令只有在您的消息开头时才会被识别。命令名称后面的文本将成为其参数。{/* min-version: 2.1.199 */}从 v2.1.199 版本起，[skills](/docs/en/skills#pass-arguments-to-skills) 是个例外：技能调用后跟更多技能（例如 `/skill-a /skill-b do XYZ`）会加载开头命名的所有技能，并将尾部文本作为参数传递给每个技能。最多可以串联六个技能。

如果您在 Claude 正在回复时发送命令，它会排队并在当前轮次结束后运行。某些命令，例如 `/status`、`/tasks` 和 `/usage`，会立即运行而不会中断回复。

## 典型工作流中的命令

大多数命令在会话的特定节点很有用，从设置项目到发布更改。

**仓库中的首次会话。** 运行 `/init` 以生成初始 `CLAUDE.md`，然后运行 `/memory` 进行调整。使用 `/mcp` 设置项目所需的任何服务器，要求 Claude 创建您想要的任何 [subagents](/docs/en/sub-agents)，并运行 `/permissions` 来设置您的批准规则。

**任务执行期间。** `/plan` 在进行大更改之前切换到计划模式。`/model` 和 `/effort` 调整您正在使用的模型及其应用的推理量。当对话变得很长时，`/context` 会显示什么内容填满了窗口，而 `/compact` 会对其进行总结以释放空间。使用 `/btw` 进行不应添加到对话历史记录中的快速旁白。

**并行运行工作。** Claude 将次要任务委托给 [subagents](/docs/en/sub-agents)，而 `/tasks` 会列出当前会话的后台工作，包括已完成的子代理。`/background` 分离整个会话以继续作为 [background agent](/docs/en/agent-view) 运行并释放您的终端。对于跨越代码库的大更改，`/batch` 会将其分解为独立的单元，并在其自己的 [worktree](/docs/en/worktrees) 中运行每个单元。有关这些方法如何关联的信息，请参见 [Run agents in parallel](/docs/en/agents)。

**在您发布之前。** `/diff` 显示更改的内容，`/code-review` 检查差异中的正确性错误和清理机会，并且可以使用 `--fix` 应用这些发现，`/review` 对 GitHub 拉取请求进行快速的单次只读审查，`/code-review <level> <pr#>` 对其进行多代理审查，而 `/security-review` 检查差异是否存在安全漏洞。`/code-review ultra` 在云中运行多代理审查。

**在会话之间。** `/clear` 在保留项目记忆的同时开始执行新任务。`/resume` 返回到较早的对话，`/branch` 分支当前对话以尝试不同的方向，而 `/fork` 将其复制到新的 [background session](/docs/en/agent-view) 中。`/teleport` 将网络会话拉入此终端，而 `/remote-control` 允许您从另一台设备继续此本地会话。

**出现问题时。** `/rewind` 将代码和对话回滚到检查点，或总结部分对话。`/doctor` 运行安装检查，诊断安装和配置问题并可予以修复，`/debug` 诊断运行时问题，而 `/feedback` 报告附带会话上下文的 Bug。

## 所有命令

下表列出了 Claude Code 中包含的所有命令。大多数是内置命令，其行为已编码至 CLI 中。标出了两种类型的条目：

* **[技能](/docs/en/skills#bundled-skills)**：一个捆绑的技能。它的工作方式与你自行编写的技能相同：将提示词交给 Claude，当相关时 Claude 也可以自动调用它。
  * {/* min-version: 2.1.215 */}`/verify` 和 `/code-review` 仅在你调用它们时运行。在 v2.1.215 之前，Claude 也可以自行运行它们。
* **[工作流](/docs/en/workflows#bundled-workflows)**：一个捆绑的 [动态工作流](/docs/en/workflows)，它将工作展开分配给多个子代理并在后台运行。

要添加你自己的命令，请参阅 [技能](/docs/en/skills)。

在下表中，`<arg>` 表示必填参数，`[arg]` 表示可选参数。

<Note>
  并非每个用户都能看到所有命令。可用性取决于你的平台、套餐和环境。例如，`/desktop` 仅在使用 Claude 订阅登录时显示在 macOS 和 Windows 上，而 `/upgrade` 不会在企业版套餐中显示。
</Note>

## MCP 提示

MCP 服务器可以公开显示为命令的提示。这些提示使用 `/mcp__<server>__<prompt>` 格式，并从连接的服务器中动态发现。有关详细信息，请参阅 [MCP 提示](/docs/en/mcp#use-mcp-prompts-as-commands)。
