  <p className="digest-feature-lede">deny 和 ask 权限规则现在可以使用 <code>Tool(param:value)</code> 语法匹配工具的输入参数。例如，<code>Agent(model:opus)</code> 会匹配请求 Opus 模型层级的子智能体生成操作。值接受 `*` 作为通配符，因此 `Agent(isolation:*)` 会匹配任意显式隔离值。</p>

  <p className="digest-feature-try">在 <code>settings.json</code> 的 deny 列表中添加参数规则：</p>

  ```json .claude/settings.json {3} theme={null}
  {
    "permissions": {
      "deny": ["Agent(model:opus)"]
    }
  }
  ```

<div className="digest-wins">
  <p className="digest-wins-title">其他改进</p>

  <div className="digest-wins-grid">
    <div>如果你没有要求丢弃本地工作，自动模式现在会阻止破坏性 git 命令（`git reset --hard`、`git clean -fd`、`git stash drop`）；除非你要求针对特定堆栈执行，否则还会阻止 <code>terraform destroy</code></div>
    <div>将新的 <code>attribution.sessionUrl</code> 设置设为 <code>false</code>，可在 Web 和 Remote Control 会话的提交及 PR 中省略 claude.ai 会话链接</div>
    <div>在 <code>/config</code> 界面中，Enter 和 Space 现在都可以更改选中的设置；Esc 现在会保存并关闭，而不是还原</div>
    <div>新增可选择启用的 <code>sandbox.allowAppleEvents</code> 设置，允许沙箱命令在 macOS 上发送 Apple Events</div>
    <div>将 <code>CLAUDE\_CLIENT\_PRESENCE\_FILE</code> 指向标记文件，可以在你位于机器旁时禁止移动推送通知</div>
    <div>长段落现在会逐行流式传输，而不是等待第一个换行符</div>
    <div>思考过程中 API 连接中断时，现在会自动重试，而不是显示“Connection closed while thinking”</div>
    <div>设置 <code>CLAUDE\_CODE\_EXPERIMENTAL\_AGENT\_TEAMS=1</code> 后，每个会话都有一个隐式团队，因此可以直接使用 Agent 工具的 <code>name</code> 参数生成队友</div>
    <div>处理嵌套 <code>.claude/skills</code> 目录中的文件时，会加载其中的技能；发生名称冲突时，嵌套技能显示为 `<dir>:<name>`，因此两者都保持可用</div>
    <div>修复在自定义 <code>ANTHROPIC\_BASE\_URL</code> 和 Microsoft Foundry 上无法读取提示词缓存的问题</div>
    <div>修复 Write 和 Edit 在网络驱动器及云同步文件夹上生成零字节或截断文件的问题</div>
  </div>
</div>
