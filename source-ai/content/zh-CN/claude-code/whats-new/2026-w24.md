# 2026 年第 24 周 · 6 月 8–12 日

> 使用 /cd 将会话移到新目录、允许子代理生成自己的子代理，以及使用安全模式排查损坏的配置。

<div className="digest-meta">
  <span>发布版本 <a href="/docs/docs/en/changelog#2-1-166">v2.1.166 → v2.1.176</a></span>
  <span>3 项功能 · 6 月 8–12 日</span>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">使用 /cd 移动会话</span>
    <span className="digest-feature-pill">v2.1.169</span>
  </div>

  <p className="digest-feature-lede">新的 <code>/cd</code> 命令可将当前会话移到不同的工作目录，而无需重建提示缓存：新目录中的 <code>CLAUDE.md</code> 会作为一条消息追加，而不是替换系统提示。会话会迁移到新目录的项目存储，因此 `--resume` 和 `--continue` 可在那里找到它。如果你以前没有在该目录中工作过，Claude 会提示你信任该目录。</p>

  <p className="digest-feature-try">无需重启，将会话移入另一个项目：</p>

  ```text Claude Code theme={null}
  > /cd ../other-project
  ```

  <a className="digest-feature-link" href="/docs/docs/en/commands#all-commands">命令参考</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">子代理可以生成子代理</span>
    <span className="digest-feature-pill">v2.1.172</span>
  </div>

  <p className="digest-feature-lede">子代理现在可以生成自己的子代理。提示下方的子代理面板会显示完整树结构：每一行都带有其后代数量，以及一条返回 <code>main</code> 的路径。子代理链的深度上限为五层，以防并发树无限扩张。</p>

  <p className="digest-feature-try">打开代理视图，在工作向外分派时观察嵌套树：</p>

  ```text Claude Code theme={null}
  > /agents
  ```

  <a className="digest-feature-link" href="/docs/docs/en/sub-agents#let-subagents-spawn-their-own-subagents">生成嵌套子代理</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">使用安全模式排查问题</span>
    <span className="digest-feature-pill">v2.1.169</span>
  </div>

  <p className="digest-feature-lede">使用 `--safe-mode` 启动 Claude Code，或设置 <code>CLAUDE\_CODE\_SAFE\_MODE</code>，即可在禁用所有自定义项的情况下启动：不会加载 <code>CLAUDE.md</code>、技能、插件、钩子、MCP 服务器以及自定义命令和代理。身份验证、模型选择、内置工具和权限仍可正常工作。如果问题在安全模式下消失，原因就在这些扩展面之一。</p>

  <p className="digest-feature-try">启动干净会话以隔离损坏的配置：</p>

  ```bash terminal theme={null}
  claude --safe-mode
  ```

  <a className="digest-feature-link" href="/docs/docs/en/debug-your-config#test-against-a-clean-configuration">针对干净配置进行测试</a>
</div>

<div className="digest-wins">
  <p className="digest-wins-title">其他改进</p>

  <div className="digest-wins-grid">
    <div><a href="/docs/docs/en/model-config#fallback-model-chains"><code>fallbackModel</code></a> 可配置最多三个回退模型，在主模型过载或不可用时按顺序尝试；`--fallback-model` 现在也适用于交互式会话</div>
    <div>会话标题现在会以对话所用语言生成；可通过 <code>language</code> 设置固定指定语言</div>
    <div>`claude agents --json` 新增 `--all` 以包含已完成的会话，并新增 <code>id</code> 和 <code>state</code> 字段；它也不再遗漏被阻塞或刚分派的会话</div>
    <div>在 <code>/plugin</code> 中浏览 marketplace 的插件时，现在会显示搜索栏</div>
    <div>新的 <code>disableBundledSkills</code> 设置和 <code>CLAUDE\_CODE\_DISABLE\_BUNDLED\_SKILLS</code> 可对模型隐藏捆绑技能、工作流和内置命令</div>
    <div>拒绝规则接受工具名称位置的 glob，因此 <code>"\*"</code> 会拒绝所有工具；拒绝规则中出现未知工具名称时，现在会在启动时发出警告</div>
    <div>跨会话消息传递得到强化：其他会话通过 <code>SendMessage</code> 中继的消息不再携带用户权限，自动模式也会阻止这些消息</div>
    <div>未设置 <code>AWS\_REGION</code> 时，Amazon Bedrock 会从 <code>\~/.aws</code> 配置文件读取 AWS 区域，<code>/status</code> 则会显示区域来源</div>
    <div>新的 <code>enforceAvailableModels</code> 托管设置会让 <code>availableModels</code> 允许列表同时约束 Default 模型</div>
    <div>Claude in Chrome 浏览器工具现在会通过单个批量调用加载，而不是逐个工具调用</div>
    <div><code>claude update</code> 会在下载前公布目标版本，而不再保持沉默</div>
    <div>新的 <code>footerLinksRegexes</code> 设置可将正则表达式匹配的链接徽章添加到页脚行</div>
  </div>
</div>
