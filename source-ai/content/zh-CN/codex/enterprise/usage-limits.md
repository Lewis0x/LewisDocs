# ChatGPT 使用限制和支出控制

> 有关完整的文档索引，请参见 [llms.txt](https://learn.chatgpt.com/llms.txt)。可通过在页面 URL 后附加 `.md` 来获取文档页面的 Markdown 版本。

ChatGPT 工作区使用限制和支出控制适用于
工作区计划下的符合条件的活动。根据计划的不同，这可以包括一些
Codex 活动。这些控制并非通用的 Codex 限制系统，且不
管理 OpenAI API 平台计费。

有关完整的管理模型，请参见
[角色和工作区权限](https://learn.chatgpt.com/docs/enterprise/roles-and-workspace-permissions)。

## 了解这些控制何时适用

在以下情况下查看 ChatGPT 工作区使用控制：

- 组织的协议使用了共享或购买的 ChatGPT 工作区
  额度。
- 符合条件的 Codex 活动可以消耗这些额度。
- 管理员需要用户防护措施、工作区级别的支出控制，或当前计划支持的用量通知。

使用控制不配置功能权利或权限，尽管
耗尽的限制可以暂停对符合条件的功能的访问。它们不影响
源系统权限，也不管理平台 API 的使用或计费。
