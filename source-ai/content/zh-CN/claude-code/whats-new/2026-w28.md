    <div>自动模式现在会阻止篡改会话对话记录文件；在无法从上下文解析的变量上运行 <code>rm -rf</code> 之前，也会先询问</div>

    <div><code>/commit-push-pr</code> 现在会自动允许向仓库配置的推送远端执行 <code>git push</code>，而不仅限于 <code>origin</code></div>
    <div>Gateway：<code>/login</code> 现在支持由 Anthropic 运营的公共网关端点</div>
    <div><code>EnterWorktree</code> 在进入项目 <code>.claude/worktrees/</code> 目录以外的 git 工作树之前会请求确认</div>
    <div>Claude Code 更新后，后台智能体会立即在后台升级到新版本，而不是等你附加时才进行缓慢的陈旧会话升级</div>
    <div>智能体视图中的行现在显示彩色状态词和分类器生成的标题，而不是原始工具调用文本；编辑、合并、评论现有 PR 或向其推送的会话，也会在 <code>claude agents</code> 中链接该 PR</div>
    <div>自动更新的二进制下载现在会流式写入磁盘，而不是缓存在内存中，从而将更新程序的峰值内存使用量降低约 400 MB</div>
    <div>后台任务通知现在会明确说明没有发生人工输入，防止对话记录中伪造的批准被执行</div>
    <div>在所有工作强度级别上，改进了 Opus 4.8 的 <code>/code-review</code> 发现质量</div>
