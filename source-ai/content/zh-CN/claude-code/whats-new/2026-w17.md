<div className="digest-wins">
  <p className="digest-wins-title">其他改进</p>

  <div className="digest-wins-grid">
    <div><a href="/docs/docs/en/interactive-mode#vim-editor-mode">Vim 可视模式</a>：在提示输入框中按 <code>v</code> 进行字符选择，或按 <code>V</code> 进行行选择，并支持操作符和可视反馈</div>
    <div>钩子现在可通过 <a href="/docs/docs/en/hooks#mcp-tool-hook-fields"><code>type: "mcp\_tool"</code></a> 直接调用 MCP 工具，因此钩子无需生成进程即可访问已连接的服务器</div>
    <div><code>/cost</code> 和 <code>/stats</code> 已合并到 <a href="/docs/docs/en/commands"><code>/usage</code></a>；旧名称仍可作为输入快捷方式使用，并会打开相应标签页</div>
    <div><code>/config</code> 的更改（主题、编辑器模式、详细输出等）现在会持久化到 <code>\~/.claude/settings.json</code>，并遵循与其他<a href="/docs/docs/en/settings">设置</a>相同的项目/本地/政策优先级</div>
    <div><a href="/docs/docs/en/sub-agents#fork-the-current-conversation">分叉子代理</a>可在外部构建中通过 <code>CLAUDE\_CODE\_FORK\_SUBAGENT=1</code> 启用：分叉会继承完整的对话上下文，而不是从头开始</div>
    <div>使用 Opus 4.6 和 Sonnet 4.6 的 Pro 与 Max 订阅者，其默认<a href="/docs/docs/en/model-config#adjust-effort-level">工作强度级别</a>现在为 <code>high</code>（此前为 <code>medium</code>）</div>
    <div>原生 macOS 和 Linux 构建用 Bash 中可用的嵌入式 <code>bfs</code> 和 <code>ugrep</code> 替换 <code>Glob</code> 与 <code>Grep</code> 工具，无需单独的工具往返即可更快搜索</div>
    <div>除 github.com 外，<code>--from-pr</code> 现在还接受 GitLab 合并请求、Bitbucket 拉取请求和 GitHub Enterprise PR URL</div>
    <div>自动模式：将 <code>"\$defaults"</code> 加入 <a href="/docs/docs/en/auto-mode-config"><code>autoMode.allow</code>、<code>soft\_deny</code> 或 <code>environment</code></a>，即可在内置列表之外添加自定义规则，而非替换内置列表</div>
    <div>新的 <a href="/docs/docs/en/plugin-dependencies#tag-plugin-releases-for-version-resolution"><code>claude plugin tag</code></a> 命令可在进行版本验证后为插件创建发布 git 标签</div>
    <div>Opus 4.7 会话现在基于模型原生的 1M 上下文窗口计算，修复了虚高的 <code>/context</code> 百分比和过早的自动压缩</div>
    <div>大型会话中的 <code>/resume</code> 最多快 67%，现在还会在重新读取过时的大型会话前询问是否先生成摘要</div>
  </div>
