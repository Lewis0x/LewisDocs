# Claude Code 学习路径

这条路径从首次运行开始，逐步建立项目记忆、权限边界和扩展能力，再深入工作原理、常见流程与自动化。建议按顺序阅读，并在真实但可回退的小任务中验证每一步。

## 1. 完成首次运行

- [快速开始](/ai/zh-CN/claude-code/quickstart)

先熟悉安装、启动和基本交互，确认 Claude Code 能在目标仓库中读取上下文并执行受控任务。

## 2. 建立长期上下文

- [记忆机制](/ai/zh-CN/claude-code/memory)

理解项目指令和持久上下文如何影响后续会话，把稳定规则与一次性任务信息分开。

## 3. 设置权限边界

- [权限管理](/ai/zh-CN/claude-code/permissions)

明确读取、修改、命令执行和外部操作的授权范围，尤其注意凭据、发布和不可逆操作。

## 4. 按需扩展能力

- [功能与扩展](/ai/zh-CN/claude-code/extensions)

在基础工作流稳定后，再引入适合团队的扩展能力，保持配置可理解、可审查。

## 5. 固化工程习惯

- [最佳实践](/ai/zh-CN/claude-code/best-practices)

把前面的能力组合成可重复的工作方式，包括任务拆分、验证、变更审查和交接。

## 6. 理解代理工作原理

- [Claude Code 的工作原理](/ai/zh-CN/claude-code/how-it-works)

理解代理循环、内置工具和上下文管理方式，知道 Claude Code 如何从收集信息推进到执行与验证。

## 7. 练习常见开发流程

- [常见工作流](/ai/zh-CN/claude-code/common-workflows)

通过代码库探索、修复缺陷、重构和测试等分步示例，把基础能力落到日常工程任务中。

## 8. 用 Hooks 自动执行动作

- [Hooks 自动化指南](/ai/zh-CN/claude-code/hooks-guide)

在关键生命周期事件上运行确定性命令，用于格式化、校验、通知和团队规则执行。

## 9. 通过 MCP 连接外部工具

- [通过 MCP 连接工具](/ai/zh-CN/claude-code/mcp)

学习连接外部服务与数据源，同时管理作用域、权限、认证和工具输出带来的风险。

## 10. 使用专用子代理

- [创建自定义子代理](/ai/zh-CN/claude-code/subagents)

把边界清晰的研究或审查任务放入独立上下文，配置专用提示、工具与权限，并控制并行工作的成本。
