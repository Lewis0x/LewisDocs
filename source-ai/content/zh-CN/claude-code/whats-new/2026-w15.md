    <video autoPlay muted loop playsInline className="w-full" src="https://mintcdn.com/claude-code/aFXPQxiBOW99MHS3/images/whats-new/monitor-tool.mp4?fit=max&auto=format&n=aFXPQxiBOW99MHS3&q=85&s=f4156c15a0999de5c5157f54a3117c89" data-path="images/whats-new/monitor-tool.mp4" />

  <p className="digest-feature-try">让 Claude 在你继续工作时监视某项内容：</p>

  ```text Claude Code theme={null}

  ```

  <p className="digest-feature-try">此功能可与 <code>/loop</code> 配合使用，后者现在能够自主调度：省略时间间隔后，Claude 会根据任务安排下一次触发，或改用 Monitor 工具来完全避免轮询。</p>

  ```text Claude Code theme={null}
  > /loop check CI on my PR
  ```

  <p className="digest-wins-title">其他改进</p>

  <div className="digest-wins-grid">
    <div>聚焦视图：在无闪烁模式下按 <code>Ctrl+O</code>，可将视图折叠为你上一条提示词、带差异统计的单行工具摘要，以及 Claude 的最终响应</div>
    <div>登录屏幕新增引导式 <a href="/docs/docs/en/amazon-bedrock">Amazon Bedrock</a> 和 <a href="/docs/docs/en/google-vertex-ai">Google Cloud 的 Agent Platform</a> 设置向导：选择“3rd-party platform”，即可逐步完成身份验证、区域选择、凭据检查和模型固定</div>
    <div><code>/agents</code> 采用选项卡式布局：Running 选项卡显示实时子智能体和 <code>● N running</code> 计数，Library 选项卡中还提供 Run agent 和 View running instance 操作</div>
    <div>对于 API 密钥、Amazon Bedrock、Google Cloud 的 Agent Platform、Microsoft Foundry、Team 和 Enterprise 用户，默认工作强度级别现在为 <code>high</code>（使用 <code>/effort</code> 控制）</div>
    <div><code>/cost</code> 会向订阅用户显示按模型划分的费用明细和缓存命中明细</div>
    <div><code>/release-notes</code> 现在是交互式版本选择器</div>
    <div>状态行：新增 <code>refreshInterval</code> 设置，每隔 N 秒重新运行命令；JSON 输入中新增 <code>workspace.git\_worktree</code></div>
    <div><code>CLAUDE\_CODE\_PERFORCE\_MODE</code>：Edit/Write 遇到只读文件时会失败并提示 <code>p4 edit</code>，而不是静默覆盖</div>
    <div>现在默认信任操作系统 CA 证书存储，因此企业 TLS 代理无需额外设置即可工作（设置 <code>CLAUDE\_CODE\_CERT\_STORE=bundled</code> 可选择退出）</div>
    <div>由 Mantle 提供支持的 Amazon Bedrock：设置 <code>CLAUDE\_CODE\_USE\_MANTLE=1</code></div>
    <div>强化 Bash 工具权限：反斜杠转义的标志、环境变量前缀、<code>/dev/tcp</code> 重定向和复合命令现在都会正确提示</div>
    <div><code>UserPromptSubmit</code> 钩子可以通过 <code>hookSpecificOutput.sessionTitle</code> 设置会话标题</div>
