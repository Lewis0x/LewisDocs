# 功能成熟度

一些 ChatGPT 和 Codex 功能在发布时会带有成熟度标签，以便您了解每个功能的可靠程度、可能的变化以及预期的支持级别。

| 成熟度            | 含义                                                                                                            | 指导建议                                                                       |
| ----------------- | ------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| 开发中            | 尚未准备好使用。                                                                                                  | 请勿使用。                                                                     |
| 实验性            | 不稳定，OpenAI 可能会移除或更改。                                                                                    | 使用风险自负。                                                                 |
| 测试版            | 可供广泛测试；在大多数方面已完整，但某些方面可能会根据用户反馈而变化。                                                | 适用于大多数评估和试点；预计会有小幅变化。                                      |
| 稳定版            | 完全支持、已编写文档并可供广泛使用；行为和配置随时间保持一致。                                                          | 可安全用于生产环境；移除通常会经过弃用流程。                                     |
