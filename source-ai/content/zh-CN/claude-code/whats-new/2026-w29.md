# 第 29 周 · 2026 年 7 月 13–17 日

> 通过 MCP 连接器将实时数据引入已发布的 Artifacts，并在新的屏幕阅读器模式下配合屏幕阅读器使用 Claude Code。

  <p className="digest-feature-lede">现在，每当有人查看已发布的 Artifact 时，它都可以调用 MCP 连接器，因此仪表板显示的是实时数据，并可按需执行操作，而不是呈现构建该页面的会话快照。每次调用都会通过查看者账户自己的连接运行，查看者则会在页面首次调用连接器前批准访问。本周还新增了公开共享链接、Team 和 Enterprise 方案中的共享编辑者角色，以及从 Claude Tag 会话创建 Artifact 的功能。</p>

    <span className="digest-feature-pill">CLI</span>

  <p className="digest-feature-lede">屏幕阅读器模式会使用朴素的线性文本替代可视化终端界面：Claude Code 不再显示框、旋转指示器和原地重绘，而是输出带标签的行，让 VoiceOver 或 NVDA 等屏幕阅读器按顺序读取，因此你可以批准权限并从头到尾审查输出。可以使用标志为单个会话启用此模式，使用 <code>CLAUDE\_AX\_SCREEN\_READER</code> 环境变量为单个 shell 启用，或使用 <code>axScreenReader</code> 设置在所有位置启用。</p>

  <p className="digest-feature-try">以屏幕阅读器模式启动会话：</p>

  ```bash terminal theme={null}
  claude --ax-screen-reader
  ```

  <a className="digest-feature-link" href="/docs/docs/en/accessibility#turn-on-screen-reader-mode">开启屏幕阅读器模式</a>
</div>

<div className="digest-wins">
  <p className="digest-wins-title">其他改进</p>

  <div className="digest-wins-grid">
    <div><code>/fork</code> 现在会将对话复制到新的后台会话，该会话在 <code>claude agents</code> 中有自己的一行，而你可以继续工作；它之前会启动的会话内分叉子智能体现在改为 <code>/subtask</code></div>
    <div>在 Amazon Bedrock、Google Cloud 的 Agent Platform 和 Microsoft Foundry 上，<a href="/docs/docs/en/permission-modes#enable-auto-mode-on-bedrock-agent-platform-or-foundry">自动模式</a>不再需要选择启用 <code>CLAUDE\_CODE\_ENABLE\_AUTO\_MODE</code>；管理员可以使用 <code>disableAutoMode</code> 将其关闭</div>
    <div>运行时间超过两分钟的 MCP 工具调用现在会自动移至后台，使会话保持可用；使用 <code>CLAUDE\_CODE\_MCP\_AUTO\_BACKGROUND\_MS</code> 调整或禁用该阈值</div>
    <div>新增 <code>claude auto-mode reset</code>，用于恢复默认自动模式配置；`--yes` 可跳过确认提示</div>
    <div>新增<a href="/docs/docs/en/corporate-launcher">企业启动器</a>支持：<code>CLAUDE\_CODE\_PROCESS\_WRAPPER</code> 或 <code>processWrapper</code> 设置会让 Claude Code 从其自身二进制文件启动的进程（例如后台服务和智能体视图会话）通过必需的包装器可执行文件运行</div>
    <div><code>vimInsertModeRemaps</code> 设置可在 vim 模式中将 <code>jj</code> 等双键插入模式序列映射为 Escape</div>
    <div>`--forward-subagent-text` 和 <code>CLAUDE\_CODE\_FORWARD\_SUBAGENT\_TEXT</code> 会在<a href="/docs/docs/en/headless">stream-json 输出</a>中包含子智能体文本和思考块</div>
    <div>会话级上限可阻止失控循环：WebSearch 调用和子智能体生成各自默认为 200 次，可通过 <code>CLAUDE\_CODE\_MAX\_WEB\_SEARCHES\_PER\_SESSION</code> 和 <code>CLAUDE\_CODE\_MAX\_SUBAGENTS\_PER\_SESSION</code> 调整</div>
    <div>“Always allow”权限规则会保存在仓库根目录，因此在 git 工作树中授予的批准会跨会话和工作树保留</div>
    <div>Amazon Bedrock、Google Cloud 的 Agent Platform 和 AWS 上的 Claude Platform 现在默认使用 Claude Opus 4.8</div>
    <div>折叠的工具摘要行会显示实时耗时计数器，因此长时间运行的工具调用会明显计时，而不是看起来像卡住一样</div>
  </div>
</div>
