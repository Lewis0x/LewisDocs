# 2026 年第 21 周 · 5 月 18–22 日

> 在 Pro 计划和 Sonnet 4.6 上使用自动模式、在 /usage 中查看哪些技能、子代理和 MCP 服务器消耗了你的计划额度，以及使用新的 /code-review 命令审查差异。

  <span>发布版本 <a href="/docs/docs/en/changelog#2-1-143">v2.1.143 → v2.1.149</a></span>
  <span>1 项功能 · 5 月 18–22 日</span>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Pro 计划上的自动模式</span>
    <span className="digest-feature-pill">CLI</span>
  </div>

  <p className="digest-feature-lede">自动模式现在可用于 Pro 计划，并在 Opus 之外支持 Sonnet 4.6。它用后台安全检查取代权限提示：常规操作不会打断你，而破坏性或可疑的操作会被阻止并呈现出来。</p>

  <p className="digest-feature-try">更新 Claude Code，然后使用 Shift+Tab 循环切换模式；当你的账户满足要求后，自动模式会出现在循环中：</p>

  ```bash terminal theme={null}
  claude update
  ```

  <p className="digest-feature-try">该命令会输出 <code>Successfully updated</code> 和新版本号；如果无需更新，则输出 <code>Claude Code is up to date</code>。启用自动模式后，提示页脚会显示 <code>auto mode on</code>。</p>

  <a className="digest-feature-link" href="/docs/docs/en/permission-modes#eliminate-prompts-with-auto-mode">自动模式要求</a>
</div>

<div className="digest-wins">
  <p className="digest-wins-title">其他改进</p>

  <div className="digest-wins-grid">
    <div><a href="/docs/docs/en/costs#track-your-costs"><code>/usage</code></a> 现在会按类别细分哪些内容正在消耗你的计划额度，并将近期用量归属到技能、子代理、插件和各个 MCP 服务器</div>
    <div>CLI 中的“Extra usage”已更名为“usage credits”，<code>/extra-usage</code> 也改为 <code>/usage-credits</code>。旧名称仍然有效。该命令要求通过 <code>/login</code> 登录 claude.ai 订阅，使用 API 密钥身份验证时不可用。</div>
    <div>新的 <a href="/docs/docs/en/code-review"><code>/code-review</code></a> 命令会以指定工作强度级别报告正确性错误，例如 <code>/code-review high</code>；<code>--comment</code> 会将发现作为 GitHub PR 行内评论发布。<code>/simplify</code> 仍作为单独的纯清理审查保留。</div>
    <div>后台会话现在会与交互式会话一起显示在 <code>/resume</code> 中，并标记为 <code>bg</code>；在 <code>claude agents</code> 中使用 <code>Ctrl+T</code> 固定的会话在空闲时仍会保持活动</div>
    <div><code>claude agents --json</code> 以 JSON 形式列出活动会话，可用于状态栏和会话选择器等脚本</div>
    <div>Amazon Bedrock、Google Cloud Agent Platform 和 Microsoft Foundry 用户现在默认启用 Windows 上的 PowerShell 工具；设置 <code>CLAUDE\_CODE\_USE\_POWERSHELL\_TOOL=0</code> 可选择退出</div>
    <div>当另一个已启用插件依赖目标插件时，<code>claude plugin disable</code> 现在会拒绝执行；<code>claude plugin enable</code> 则会强制启用传递依赖</div>
    <div><code>/plugin</code> marketplace 浏览窗格会显示预计上下文成本，Discover 和 Browse 屏幕则会在安装前列出插件的命令、代理、技能、钩子以及 MCP/LSP 服务器</div>
    <div>新的 <code>worktree.bgIsolation: "none"</code> 设置允许后台会话直接编辑工作副本而不使用 <code>EnterWorktree</code>，适用于不便使用 worktree 的仓库</div>
    <div>Markdown 输出会渲染 GFM 任务列表复选框，<code>/diff</code> 详细视图也可通过键盘滚动</div>
    <div>检测到 GitHub 仓库和 PR 信息时，状态行 JSON 输入现在会包含这些信息</div>
    <div>企业版：<code>allowAllClaudeAiMcps</code> 托管设置会在 <code>managed-mcp.json</code> 之外加载 claude.ai 云 MCP 连接器</div>
  </div>
</div>
