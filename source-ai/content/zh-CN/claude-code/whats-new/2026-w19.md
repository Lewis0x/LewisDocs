# 2026 年第 19 周 · 5 月 4–8 日

> 从 .zip 归档和 URL 加载插件、使用 Ctrl+R 跨所有项目搜索命令历史记录、从本地 HEAD 或远程默认分支创建新 worktree，以及通过自动模式硬拒绝规则无条件阻止操作。

  <p className="digest-feature-lede">除目录外，`--plugin-dir` 现在还接受 <code>.zip</code> 插件归档；新的 `--plugin-url` 标志则会从 URL 获取插件归档，供当前会话使用。这适合在将插件加入 marketplace 之前进行试用，或从制品存储分发内部插件。</p>

  <p className="digest-feature-try">直接从 URL 加载插件：</p>

  ```bash terminal theme={null}

  ```

  <p className="digest-feature-lede"><code>Ctrl+R</code> 反向搜索现在默认覆盖所有项目中的全部提示，恢复了 v2.1.124 之前的行为。搜索时按 <code>Ctrl+S</code> 可将范围重新缩小到当前项目或会话。当你记得上周在另一个仓库运行过某条命令，却不想费力翻找时，这会很方便。</p>

<div className="digest-wins">
  <p className="digest-wins-title">其他改进</p>

  <div className="digest-wins-grid">
    <div>新的 <code>worktree.baseRef</code> 设置（<code>fresh</code> | <code>head</code>）控制 <code>--worktree</code>、<code>EnterWorktree</code> 工具和代理隔离 worktree 是从远程默认分支还是本地 <code>HEAD</code> 创建分支；默认值 <code>fresh</code> 可避免未推送的提交进入新 worktree</div>
    <div>新的 <code>settings.autoMode.hard\_deny</code> 规则会在自动模式下无条件阻止匹配的操作，不受允许例外影响，适用于即使存在更宽泛的允许规则也绝不应自动运行的操作</div>
    <div>钩子现在通过 `effort.level` JSON 输入字段和 `$CLAUDE_EFFORT` 环境变量接收当前工作强度级别，Bash 工具命令也可以读取 <code>\$CLAUDE\_EFFORT</code></div>
    <div><code>CLAUDE\_CODE\_DISABLE\_ALTERNATE\_SCREEN=1</code> 可选择退出全屏备用屏幕渲染器，并将对话保留在终端原生回滚缓冲区中</div>
    <div><code>CLAUDE\_CODE\_PACKAGE\_MANAGER\_AUTO\_UPDATE</code> 允许 Homebrew 或 WinGet 安装在后台执行升级并提示重启</div>
    <div><code>CLAUDE\_CODE\_SESSION\_ID</code> 现在会出现在 Bash 工具子进程环境中，与传递给钩子的 <code>session\_id</code> 一致</div>
    <div><code>/mcp</code> 现在会显示已连接服务器的工具数量，并标记连接后拥有 0 个工具的服务器</div>
    <div><code>--channels</code> 现在可用于 Console（API 密钥）身份验证</div>
    <div>Bash、钩子、MCP 和 LSP 等子进程不再继承 <code>OTEL\_\*</code> 环境变量，因此通过 Bash 工具运行的 OTEL 插桩应用不会再获取 CLI 自身的 OTLP 端点</div>
    <div>子代理进度摘要现在会命中提示缓存，使 <code>cache\_creation</code> 令牌成本降低约 3 倍</div>
    <div>多项 OAuth 和凭据可靠性修复：并行会话不再因刷新令牌竞态而在刷新后陷入 401 死路；多个服务器并发刷新时不再丢失 MCP OAuth 刷新令牌；并修复了并发写入凭据造成的罕见登录循环</div>
    <div>新的 <code>parentSettingsBehavior</code> 管理键允许管理员选择让 SDK <code>managedSettings</code> 参与策略合并</div>
  </div>
</div>
