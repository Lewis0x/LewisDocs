# 第 26 周 · 2026 年 6 月 22–26 日

> 使用 claude mcp login 从 shell 对 MCP 服务器进行身份验证，通过 ! 前缀获取对 shell 模式命令输出的响应，并使用 /rewind 恢复 /clear 之前的对话。

</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">从 CLI 对 MCP 服务器进行身份验证</span>
    <span className="digest-feature-pill">v2.1.186</span>
  </div>

  <p className="digest-feature-lede">新增 `claude mcp login <name>` 和 `claude mcp logout <name>` 命令，可从 shell 对已配置的 MCP 服务器进行身份验证，无需使用交互式 <code>/mcp</code> 菜单。`claude mcp login` 会直接运行服务器的 OAuth 流程，`claude mcp logout` 则会清除已存储的凭据。</p>

  <p className="digest-feature-try">无需打开会话，直接为已配置的服务器运行 OAuth 流程：</p>

  ```bash terminal theme={null}
  claude mcp login sentry
  ```

  <a className="digest-feature-link" href="/docs/docs/en/mcp#authenticate-from-the-command-line">从命令行进行身份验证</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Shell 模式会响应命令输出</span>
    <span className="digest-feature-pill">v2.1.186</span>
  </div>

  <p className="digest-feature-lede">使用 <code>!</code> 前缀运行的命令，其输出进入对话记录后，现在会收到 Claude 的响应，因此你可以运行 <code>! npm test</code>，无需第二条提示词即可获得失败原因说明。此响应的成本与发送普通提示词相同。要保留之前的行为，即只将输出添加到上下文而不响应，请将 <code>respondToBashCommands</code> 设为 <code>false</code> 并写入 <code>settings.json</code>。</p>

  <p className="digest-feature-try">运行命令并获取对其输出的响应：</p>

  ```text Claude Code theme={null}
  > ! npm test
  ```

  <a className="digest-feature-link" href="/docs/docs/en/interactive-mode#shell-mode-with-prefix">使用 ! 前缀的 Shell 模式</a>
</div>

<div className="digest-wins">
  <p className="digest-wins-title">其他改进</p>

  <div className="digest-wins-grid">
    <div><code>/rewind</code> 现在可以恢复运行 <code>/clear</code> 之前的对话</div>
    <div>新增 <code>sandbox.credentials</code> 设置，用于阻止沙箱命令读取凭据文件和机密环境变量</div>
    <div>组织配置的模型限制现在会应用于模型选择器、`--model`、<code>/model</code> 和 <code>ANTHROPIC\_MODEL</code>；选择受限模型时会显示“restricted by your organization's settings”消息</div>
    <div>新增 <code>autoMode.classifyAllShell</code> 设置，可通过自动模式分类器传递所有 Bash 和 PowerShell 命令；拒绝原因现在会显示在对话记录、拒绝 toast 和 <code>/permissions</code> 中</div>
    <div>新增 <code>claude\_code.assistant\_response</code> OpenTelemetry 日志事件，其中包含模型的响应文本；已经记录提示词内容的部署在升级后会开始接收此事件，因此如需只保留提示词，请设置 <code>OTEL\_LOG\_ASSISTANT\_RESPONSES=0</code></div>
    <div>后台子智能体现在会在主会话中显示权限提示，而不是自动拒绝；对话框会显示提出请求的智能体，按 Esc 只会拒绝该工具</div>
    <div><code>/install-github-app</code> 现在可以只安装 GitHub App，跳过 Actions 工作流和机密设置步骤</div>
    <div>你在沙箱网络权限对话框中允许的主机会在会话的剩余时间内被记住，无需在每次连接时重新提示</div>
    <div>流式响应的 CPU 使用量减少约 37%，终端输出缓存导致的长会话内存增长也有所降低</div>
    <div>`/review <pr>` 现在使用与 <code>/code-review medium</code> 相同的审查引擎</div>
    <div>Bash 模式的 <code>!</code> 命令现在支持实时文件路径自动补全</div>
  </div>
</div>
