    <span className="digest-feature-title">覆盖 MCP 结果大小</span>
    <span className="digest-feature-pill">v2.1.91</span>
  </div>

  <p className="digest-feature-lede">MCP 服务器作者现在可以在特定工具的 <code>tools/list</code> 条目中设置 <code>anthropic/maxResultSizeChars</code>，提高该工具的截断上限，硬性上限为 50 万个字符。过去上限是全局的，因此偶尔返回数据库架构或完整文件树等固有大型载荷的工具会触及默认限制，结果被持久化到磁盘并以文件引用代替。按工具覆盖可在工具确实需要时让这些结果保留在行内。</p>

  <p className="digest-feature-try">在服务器的 <code>tools/list</code> 响应中为工具添加注解：</p>

  ```json highlight={5} theme={null}
  {
    "name": "get_schema",
    "description": "Returns the full database schema",
    "_meta": {
      "anthropic/maxResultSizeChars": 500000
    }
  }
  ```

  <a className="digest-feature-link" href="/docs/docs/en/mcp#raise-the-limit-for-a-specific-tool">MCP 参考</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">PATH 中的插件可执行文件</span>
    <span className="digest-feature-pill">v2.1.91</span>
  </div>

  <p className="digest-feature-lede">在插件根目录的 <code>bin/</code> 目录中放置可执行文件，启用该插件时，Claude Code 会将此目录加入 Bash 工具的 <code>PATH</code>。此后 Claude 可在任何 Bash 工具调用中直接以命令名调用该二进制文件，无需绝对路径或包装脚本。这样可以方便地将 CLI 辅助工具与调用它们的命令、代理和钩子打包在一起。</p>

  <p className="digest-feature-try">在插件根目录添加 <code>bin/</code> 目录：</p>

  ```text highlight={4, 5} theme={null}
  my-plugin/
  ├── .claude-plugin/
  │   └── plugin.json
  └── bin/
      └── my-tool
  ```

  <a className="digest-feature-link" href="/docs/docs/en/plugins-reference#file-locations-reference">插件参考</a>
</div>
