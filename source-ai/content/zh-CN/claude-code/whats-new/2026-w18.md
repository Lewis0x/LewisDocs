# 第 18 周 · 2026 年 4 月 27 日至 5 月 1 日

> Windows 上的 Claude Code 无需 Git Bash 即可运行；浏览器回调无法访问 localhost 时，claude auth login 可以接受粘贴的 OAuth 代码；claude project purge 可按项目清理本地状态；将 PR URL 粘贴到 /resume 中即可找到创建该 PR 的会话。

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">无需浏览器回调即可登录</span>
    <span className="digest-feature-pill">v2.1.126</span>
  </div>

  <p className="digest-feature-lede">浏览器回调无法访问 localhost 时，<code>claude auth login</code> 现在可以接受直接粘贴到终端中的 OAuth 代码。这涵盖了 WSL2、SSH 会话和容器等本地端口重定向无法工作的环境。同一版本还修复了慢速或代理连接以及仅支持 IPv6 的开发容器中的登录超时问题。</p>

  <p className="digest-feature-try">登录，然后粘贴浏览器中的代码：</p>

  ```bash theme={null}
  claude auth login
  ```

  <a className="digest-feature-link" href="/docs/docs/en/cli-reference#cli-commands">CLI 参考</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">claude project purge</span>
    <span className="digest-feature-pill">v2.1.124</span>
  </div>

  <p className="digest-feature-lede">删除某个项目的全部 Claude Code 状态：对话记录、任务、文件历史记录和项目配置条目。支持使用 `--dry-run` 预览、使用 `-y`/`--yes` 跳过确认、使用 `-i`/`--interactive` 进行选择，以及使用 `--all` 清除所有项目。</p>

  <p className="digest-feature-try">预览将要删除的内容：</p>

  ```bash theme={null}
  claude project purge --dry-run
  ```

  <p className="digest-feature-try">然后实际运行：</p>

  ```bash theme={null}
  claude project purge
  ```

  <a className="digest-feature-link" href="/docs/docs/en/cli-reference">CLI 参考</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">通过 PR URL 恢复会话</span>
    <span className="digest-feature-pill">v2.1.122</span>
  </div>

  <p className="digest-feature-lede">使用 <code>gh pr create</code> 创建拉取请求时，Claude Code 会将其与生成该请求的会话关联。现在，只需 PR URL 即可返回该会话，无需记住会话名称。</p>

  <p className="digest-feature-try">打开会话选择器：</p>

  ```text Claude Code theme={null}
  > /resume
  ```

  <p className="digest-feature-try">将 PR URL 粘贴到选择器中。粘贴内容的第一个字符会让你进入搜索模式，列表将筛选为创建该 PR 的会话。按 Enter 键即可恢复。GitHub、GitHub Enterprise、GitLab 和 Bitbucket 的拉取请求及合并请求 URL 均可使用。</p>

  ```text Claude Code theme={null}
  https://github.com/your-org/your-repo/pull/1234
  ```

  <p className="digest-feature-try">要打开已经按 PR 筛选的选择器，请在命令行中传入 PR 编号：</p>

  ```bash theme={null}
  claude --from-pr 1234
  ```

  <a className="digest-feature-link" href="/docs/docs/en/sessions#use-the-session-picker">会话：使用会话选择器</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">无需 Git Bash 的 Windows 支持</span>
    <span className="digest-feature-pill">Windows</span>
  </div>

  <p className="digest-feature-lede">不再要求安装 Git for Windows。没有 Bash 时，Claude Code 会使用 PowerShell 作为 shell 工具；启用 PowerShell 工具后，则会将其视为主要 shell。现在还会自动检测通过 Microsoft Store 安装的 PowerShell 7、未加入 PATH 的 MSI 安装版本，或 <code>.NET</code> 全局工具。</p>

  <a className="digest-feature-link" href="/docs/docs/en/setup">设置指南</a>

<div className="digest-wins">
  <p className="digest-wins-title">其他改进</p>

  <div className="digest-wins-grid">
    <div>MCP 服务器可以在配置中使用 <code>alwaysLoad: true</code>，选择不延迟加载工具搜索，从而使该服务器的所有工具始终可用</div>
    <div>新增 <code>claude plugin prune</code>，用于删除孤立的自动安装插件依赖项；<code>plugin uninstall --prune</code> 也会执行级联清理</div>
    <div><code>/skills</code> 现在提供输入即筛选的搜索框，无需滚动即可在长列表中查找技能</div>
    <div><code>PostToolUse</code> 钩子可以通过 <code>hookSpecificOutput.updatedToolOutput</code> 替换任意工具的输出，不再局限于 MCP 工具</div>
    <div>新增 <a href="/docs/docs/en/ultrareview"><code>claude ultrareview</code></a> 子命令，可从 CI 或脚本以非交互方式运行 <code>/ultrareview</code>：将发现输出到 stdout（使用 <code>--json</code> 输出原始结果），完成时退出码为 0，失败时为 1</div>
    <div><code>--dangerously-skip-permissions</code> 现在会绕过对 <code>.claude/</code>、<code>.git/</code>、<code>.vscode/</code>、shell 配置文件和其他先前受保护路径的写入提示，但灾难性删除命令仍会提示，作为安全保障</div>
    <div><code>/model</code> 选择器可以列出网关 <code>/v1/models</code> 端点中的模型，前提是 <code>ANTHROPIC\_BASE\_URL</code> 指向兼容 Anthropic 的网关；自 v2.1.129 起，可通过 <code>CLAUDE\_CODE\_ENABLE\_GATEWAY\_MODEL\_DISCOVERY=1</code> 选择启用</div>
    <div>MCP 服务器启动期间遇到瞬时错误时，现在会自动重试最多 3 次，而不是保持断开状态</div>
    <div><code>ANTHROPIC\_BEDROCK\_SERVICE\_TIER</code> 用于选择 Amazon Bedrock 服务层级：<code>default</code>、<code>flex</code> 或 <code>priority</code></div>
    <div><code>/terminal-setup</code> 会启用 iTerm2 的剪贴板访问设置，使 <code>/copy</code> 可以工作，包括从 tmux 中复制</div>
    <div>Google Cloud 的 Agent Platform 现在支持基于 X.509 证书的工作负载身份联合（mTLS ADC）</div>
    <div>修复多项严重内存泄漏：包含大量图像的会话、在大型对话记录历史上运行 <code>/usage</code>，以及没有进度事件的长时间运行工具</div>
  </div>
</div>
