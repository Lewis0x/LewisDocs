<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">条件钩子</span>
    <span className="digest-feature-pill">v2.1.85</span>
  </div>

  <p className="digest-feature-lede">钩子现在可以使用权限规则语法声明 <code>if</code> 字段。你的预提交检查只会为 <code>Bash(git commit \*)</code> 启动，而不是为每次 Bash 调用启动，从而减少繁忙会话中的进程开销。</p>

  <p className="digest-feature-try">将钩子的作用范围仅限定为 Git 提交：</p>

  ```json .claude/settings.json {5} theme={null}
  {
    "hooks": {
      "PreToolUse": [{
        "hooks": [{
          "if": "Bash(git commit *)",
          "type": "command",
          "command": ".claude/hooks/lint-staged.sh"
        }]
      }]
    }
  }
  ```

  <a className="digest-feature-link" href="/docs/docs/en/hooks">钩子参考</a>
</div>
