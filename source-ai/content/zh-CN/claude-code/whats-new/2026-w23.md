# 2026 年第 23 周 · 6 月 1–5 日

> 在 Amazon Bedrock、Google Cloud Agent Platform 和 Microsoft Foundry 上运行自动模式；在 acceptEdits 模式下写入可运行代码的文件前发出提示；使用 /plugin list 列出已安装插件；以及为托管部署要求获批的版本范围。

  <span>发布版本 <a href="/docs/docs/en/changelog#2-1-158">v2.1.158 → v2.1.165</a></span>
  <span>4 项功能 · 6 月 1–5 日</span>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Amazon Bedrock、Google Cloud Agent Platform 和 Microsoft Foundry 上的自动模式</span>
    <span className="digest-feature-pill">v2.1.158</span>
  </div>

  <p className="digest-feature-lede">自动模式现在可在 Amazon Bedrock、Google Cloud Agent Platform 和 Microsoft Foundry 上与 Opus 4.7、Opus 4.8 配合使用，以后台安全检查取代第三方提供商上的权限提示。设置 <code>CLAUDE\_CODE\_ENABLE\_AUTO\_MODE=1</code> 即可选择启用。</p>

  <p className="digest-feature-try">在第三方提供商上选择启用，然后使用 Shift+Tab 切换到自动模式：</p>

  ```bash terminal theme={null}
  export CLAUDE_CODE_ENABLE_AUTO_MODE=1
  ```

  <a className="digest-feature-link" href="/docs/docs/en/permission-modes#enable-auto-mode-on-bedrock-agent-platform-or-foundry">第三方提供商上的自动模式</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">更安全的自动编辑</span>
    <span className="digest-feature-pill">v2.1.160</span>
  </div>

  <p className="digest-feature-lede">现在，即使处于 <code>acceptEdits</code> 模式，Claude Code 在写入可运行代码的文件前也会提示。受保护集合包括 <code>.zshenv</code> 和 <code>.bash\_login</code> 等 shell 启动文件、<code>\~/.config/git/</code> 下的 git 配置，以及 <code>.npmrc</code>、<code>.bazelrc</code> 和 <code>.pre-commit-config.yaml</code> 等构建工具配置。除 <code>bypassPermissions</code> 外，任何模式都绝不会自动批准这些写入。</p>

  <p className="digest-feature-try">在 acceptEdits 模式下工作；Claude 现在会在写入这些文件前暂停：</p>

  ```bash terminal theme={null}
  claude --permission-mode acceptEdits
  ```

  <a className="digest-feature-link" href="/docs/docs/en/permission-modes#protected-paths">受保护路径</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">使用 /plugin list 列出已安装插件</span>
    <span className="digest-feature-pill">v2.1.163</span>
  </div>

  <p className="digest-feature-lede">新的 <code>/plugin list</code> 命令无需打开 <code>/plugin</code> 菜单，即可在行内输出已安装的插件；在 shell 中也可使用 <code>claude plugin list</code>。在交互形式中，添加 `--enabled` 或 `--disabled` 可只显示处于对应状态的插件。</p>

  <p className="digest-feature-try">列出当前已开启的插件：</p>

  ```text Claude Code theme={null}
  > /plugin list --enabled
  ```

  <a className="digest-feature-link" href="/docs/docs/en/plugins-reference#plugin-list">插件命令</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">托管部署的版本要求</span>
    <span className="digest-feature-pill">v2.1.163</span>
  </div>

  <p className="digest-feature-lede">两个托管设置 <code>requiredMinimumVersion</code> 和 <code>requiredMaximumVersion</code> 允许组织要求使用获批的 Claude Code 版本范围。范围之外的客户端会在启动时退出，并告知用户通过组织指定的方法进行更新。<code>claude update</code>、<code>claude install</code> 和 <code>claude doctor</code> 仍可运行，以便用户完成恢复。</p>

  <p className="digest-feature-try">在托管设置中添加版本下限，使较旧的客户端拒绝启动：</p>

  ```json managed-settings.json theme={null}
  {
    "requiredMinimumVersion": "2.1.163"
  }
  ```

  <a className="digest-feature-link" href="/docs/docs/en/admin-setup#decide-what-to-enforce">决定要强制执行的内容</a>
</div>

<div className="digest-wins">
  <p className="digest-wins-title">其他改进</p>

  <div className="digest-wins-grid">
    <div><a href="/docs/docs/en/workflows">动态工作流</a>的触发关键词已从 <code>workflow</code> 改为 <code>ultracode</code>；用自己的语言要求工作流仍然有效，该关键词会在提示中以紫色高亮显示</div>
    <div><a href="/docs/docs/en/hooks">Stop 和 SubagentStop 钩子</a>可以返回 <code>hookSpecificOutput.additionalContext</code>，向 Claude 提供反馈并让当前轮次继续，而不会被视为错误</div>
    <div><code>claude mcp</code> 的 list、get 和 add 不再输出机密：不会展开环境变量引用，并会遮盖凭据标头和 URL 中的机密</div>
    <div>并行工具批次中某条 Bash 命令失败时不再取消其他命令；每个工具都会独立返回自己的结果</div>
    <div>使用单文件 <code>grep</code>、<code>egrep</code> 或 <code>fgrep</code> 查看文件后，编辑该文件不再需要先单独执行 Read</div>
    <div>现在，点击自动补全菜单中的命令会将其填入提示，而不是立即运行；按 Enter 才会执行</div>
    <div>在 `--tools` 中列出 <code>Grep</code> 或 <code>Glob</code>，现在会在带嵌入式搜索的原生构建中提供专用搜索工具，而不会静默忽略这些名称</div>
    <div><code>/effort</code> 现在会确认所选级别将持久化为新会话的默认值</div>
    <div><code>OTEL\_RESOURCE\_ATTRIBUTES</code> 的值现在会作为标签附加到指标数据点，因此你可以按团队或仓库等自定义维度细分使用情况指标</div>
    <div>随着编辑器品牌重塑，Windsurf 在 <code>/ide</code>、<code>/terminal-setup</code> 和 <code>/scroll-speed</code> 中更名为 Devin Desktop</div>
    <div><code>/btw</code> 新增 <code>c to copy</code> 快捷键，可将原始 Markdown 答案复制到剪贴板</div>
  </div>
</div>
